# ApolloCalc-CAS v2.0.0 版本说明

> 发布日期：2026-10-26

## 一句话

双侧同步的多变量引擎升级：C 侧 Pro 层新增三项能力且静态内存零增量，JS 侧多变量模块
正式入库并补齐矩阵与特殊函数。

## 新增能力

### C 侧（C/128KB-ProTEXT）

| 能力 | 入口 | 内存代价 |
|---|---|---|
| 多变量符号求导 d/dx、d/dy | `ac_pro_diff_multi` | 0 B |
| 多变量多项式积分（要求系数可精确整除） | `ac_pro_integrate_multi` | 0 B |
| 三角函数查表改为编译期常量表 | `AC_PRO_MATH_LUT_CONST`（默认开） | 静态内存 −16416 B |

- 通过 281 项测试；退化构建产物与上游同构的性质保持有效。
- 查表常量化的数值精度与原先运行时填充一致。
- `AC_PRO_MATH_LUT_CONST=0` 可整体回退到旧行为。

### JS 侧（JS/128KB）

| 能力 | 入口 | 测试数 |
|---|---|---|
| 多变量多项式 + 符号求导 | `ApolloMultivar.diff` | 194 |
| 矩阵基础运算（乘 / 转置 / ≤3×3 行列式与逆） | `ApolloMatrix` | 39 |
| 特殊函数 `erf` / `gamma` / `lgamma` | `ApolloSpecial` | 33 |

- 通过 603 项测试；Node 与浏览器（经典脚本、ESM 两条通道）全部覆盖。
- 三个模块自包含，既有 9 个 core 文件零改动；旧接口原样保留，新能力经
  `multivar` / `matrix` / `special` 三个命名空间访问。

## 边界

- JS 矩阵为 ≤3×3 闭式实现；12×12 完整矩阵运算（秩 / LU / QR / 特征值）仍是 C 独有能力。
  12 元线性方程组两侧均有，不在此列。
- 多变量积分只支持多项式且要求系数精确整除——不返回近似值是设计取舍。
- 上游 `C/128KB/` 保持只读冻结。
- 内核文件 175142 B 已越过 128 KiB 文件线，属本版有意取舍：项目名指的是设备堆预算，
  而运行时静态池仅 22416 B，距 96 KB 水位门禁余量充足。

## 下一步

1. 多变量 Groebner 基；
2. JS 内核压缩构建（回到 128 KiB 文件线）；
3. 稀疏线性方程组与任意精度小数（已在 v2.1.0 落地）。
