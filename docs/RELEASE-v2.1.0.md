# ApolloCalc-CAS v2.1.0 版本说明

> 发布日期：2026-10-27

## 一句话

本版为 C 侧专项：新增稀疏线性方程组求解与 180 位任意精度定点十进制运算，
JS 侧零改动。

## 新增能力

### 稀疏线性方程组（`ac_pro_sparse_solve`）

| 项 | 说明 |
|---|---|
| 规模 | n ≤ 32、非零元 ≤ 320 |
| 输入 | 三元组数组（行号、列号、值）+ 右端项；顺序任意，重复坐标自动合并，精确零丢弃 |
| 输出 | 解向量、消元后右端项、行交换记录 |
| 失败处理 | 规模超限、主元过小、奇异、填充溢出、下标非法均返回对应错误码 |

输入与消元填充共享同一份 320 非零元容量；接近上限时返回溢出错误，不会静默丢项或降精度。
全程无递归、无动态内存分配。

### 任意精度定点十进制（`ac_pro_dec_*`）

| 项 | 说明 |
|---|---|
| 精度 | 180 位有效数字，标度范围 ±2^31 |
| 接口 | 窄接口（解析 / 格式化，5 个操作数槽）+ 宽接口（加减乘除，字符串进出） |
| 语法 | `[+-]?digits[.digits]`，`.5`、`5.` 合法；无指数记法、无千分位 |
| 输出 | 一律规范形（无尾随小数零、零无符号、整数无小数点） |
| 失败处理 | 位数超限、除零、超出容量、缓冲区不足均返回对应错误码 |

除法在 180 位上限处截断并返回「不精确」状态码；无法在容量内精确表示时返回溢出错误，
不返回错值。两项能力复用既有内存池，内核静态内存维持 42608 B。

## 升级与兼容性

- **C 侧**：无既有 API 变更。退化构建（`AC_PRO_DEGRADED=1`）下两个新模块整体编译出局，
  与上游同构的性质保持有效。
- **JS 侧**：零改动，仍为 12 个测试文件 603 项。

## 边界

- 稀疏求解按较小的方案交付（n ≤ 32 / 非零元 ≤ 320）；更大规模（n ≤ 48 / 512）未实现。
- 定点小数无指数记法；超出表示域一律报错。
- 两项能力均为 C 独有，JS 侧暂无对等实现。
- 上游 `C/128KB/` 保持只读冻结。

2. JS 内核压缩构建（v2.2.0 已落地）；
3. 稀疏求解更大规模档位按需立项。
