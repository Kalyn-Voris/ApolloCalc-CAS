# C/64KB — C99 对等实现

- **状态**：**已完成（v1.0.0，2026-10-12）**
- **堆限制**：64KB（全部静态分配，`.bss` 段，禁止 malloc/free）
- **目标平台**：Cortex-M4 / ESP32 级别 MCU（无 OS 或 RTOS，无堆）

## 功能对等承诺（已兑现）

与 [JS/64KB](js-64kb.md) 逐功能对等：解析、RPN 求值、采样法系数提取、
二次/三次/四次求根、6 元线性方程组、三分量精确形式、残差回验与全部防护门禁。
`tests/` 下的三份共享 JSON 用例已通过跨版本冒烟比对给出与 JS 版一致的结果
（见"跨语言验证"，50/50 用例一致）。

在 JS 64KB 之外追加三个 C 独有层：数论（第 7 轮）、进制转换 + 分数显示（第 8 轮）、
CRC32/SHA-256/Base64/定点数工具（第 9 轮）。

## 功能清单

| 批次 | 模块 | 内容 |
|:---|:---|:---|
| 第一批（对等 JS 64KB） | ac_parser | UTF-8 多字节符号还原（π/×/÷/√/−）、隐式乘法、科学计数法 |
| | ac_evaluator | RPN 求值、12 函数、DEG/RAD、池化无堆 |
| | ac_exact | 三分量精确形式 (num/den)·√rad，int64 + safe 原语 |
| | ac_solvers | 二次精确组装 / 三次（不可约三角法）/ 四次（笛卡尔分解降次链）、6 元线性方程组、残差回验、preCheck/guardDegree/内存水位门禁 |
| | ac_math | 基础函数 + 可选三角查表（AC_MATH_USE_LUT，1024 项，实测最大误差 4.7e-6） |
| | ac_complex | 六寄存器复数四则 + cSqrt + cPowInt |
| 第二批（C 独有） | ac_numtheory | gcd/lcm、6k±1 试除素数、质因数分解、nCr/nPr（每步 gcd 约分防溢出误报） |
| | ac_base | 2/8/10/16 进制（对齐 JS 128KB decToBase 行为）、分数三模式显示（假分数/带分数/AUTO，C 独有） |
| | ac_util | CRC32（0xEDB88320 懒表）、SHA-256（FIPS 180-4）、Base64（RFC 4648）、定点数（10^-6 标度，safe 原语溢出预检） |

## 编译约束（实际生效）

```bash
gcc -std=c99 -O2 -Wall -Wextra -Wstrict-prototypes -Werror \
    -Wl,--wrap=malloc -Wl,--wrap=free -o test_runner ...
```

- `-std=c99`：不依赖 GCC 扩展，保证可移植到 MCU 工具链
- `-Wall -Wextra -Werror`：零警告纪律
- 无动态内存、无递归、无变长数组；浮点统一 `double`
- MinGW 平台差异已消化：printf 64 位用 `%I64d` 条件宏；CRT 启动期堆调用经
  GetProcAddress 转发（裸机无此问题）

## 内存账本（主要静态池，设计口径）

| 模块 | 池 | 字节 |
|:---|:---|---:|
| parser | token 256×int32 + number 128×double + matrix 42×double | 2384 |
| evaluator | RPN 256×int32 + eval 栈 64×double + op 栈 64×int32 | 1792 |
| exact | 三分量 + approx + valid | ~36 |
| solvers | 6 槽根 re/im + 6 槽精确三分量 + coeffs[5] | ~304 |
| complex | 六寄存器 ×double | 48 |
| numtheory | primes 16×int64 + exps 16×int | 192 |
| base | 字符码缓冲 64×int32 | 260 |
| util | CRC 表 256×uint32 + Base64 反查表 256×int8 | 1280 |
| math（LUT=1 时） | sin/cos 表 2×1024×double | 16384（默认关：0） |
| **合计** | 默认构建 | **≈ 6.3KB** |
| | LUT=1 | ≈ 22.1KB |

均远低于 64KB 预算；不含代码段、`.rodata`（SHA K/H 常量表 ~288B）与工具链 CRT。

## 测试规模

- **565 项测试全绿**（默认构建）/ **578**（LUT=1），0 失败，编译零警告
- 分布：parser 15 / evaluator 53 / exact 76 / solvers 61 / math 54(+13) / complex 47 /
  numtheory 123 / base 73 / util 63
- 零堆验证：`--wrap` 运行期双保险 + `nm` 达标口径无静态 malloc/free/realloc 符号

## 跨语言验证

- **XL 用例**（node test/test_*_xlang.js，基准 JS/64KB/src 只读）：
  XL01-XL12 精确形式（num/den/rad/valid 全一致）、XL01-XL19 求解（1e-9）、
  XL-M01-XL-M15 数学函数（1e-9）、XL-C01-XL-C12 复数（1e-9）
- **全量冒烟**（第 10 轮）：共享 JSON 转录 50 例，C（smoke_runner）vs JS（tests/bench/js-smoke.js）
  数值 diff：**50/50 一致，0 处 > 1e-9**（tests/bench/SMOKE-DIFF.md）
- 已知良性差异：C `cbrt()` vs JS `pow(x,1/3)`、libm `acos/cos` vs V8 内建 —— 仅 ulp 级，
  实测最大冒烟差异 4.04e-21
