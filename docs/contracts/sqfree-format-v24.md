## 1. 动机与用途

v2.4.0 功能 9(单变量多项式 square-free 分解与重根重数)是双侧并行开发的功能
(C 侧归 C 组 feat/c-eigen,JS 侧归 JS 组,ROADMAP.md:179 预告),而 (根, 重数) 列表是
**字符串进、字符串出**的功能:没有共享数据结构,只有共享文本。C 侧 Durand-Kerner
数值求根管线现成(ac_pro_solvers_ext.c:88,5..8 次),但它**不分重数**——重根按重数
重复输出,是 ROADMAP.md:151 点名的已知不完整语义;JS 侧高次求根止步 4 次
(ROADMAP.md:23)。两侧若各自理解输出串,重数标注、根序、错误码任何一处漂移,
共享契约 JSON 对拍即全面失配、且无法定位是谁错。

因此先于两侧任何代码,把以下边界一次定死(ode-format-v23 同机制):

1. **输入文法**——什么串合法、什么串以哪个错误码拒绝(含非整系数、次数、零多项式
   三类拒绝);
2. **重数的来源**——重数由整系数 GCD 的 square-free 分解层指标**精确**决定,浮点比较
   **永不**参与重数合并(ROADMAP.md:149 评审补钉的核心主张);
3. **根的路径与标注**——1..4 次因子走精确根式管线标 `e`、5..8 次因子走 DK 迭代管线
   标 `d`,标注字母与路由规则写死(§5.1);
4. **数值格式化**——根值如何变成十进制串,与 ODE 契约 §5.1 同一 fmt,使 C 的
   `double` 与 JS 的 `number` 在同一输入上得到同一字符串;
5. **错误码语义**——一套数值,两侧同值,可精确比较(CONTRIBUTING.md:96)。

用途:两侧实现者按本文件写码与写测试;收尾组按本文件扩展 `tests/polynomials.json`
(ROADMAP.md:152);后续版本扩多项式能力时,本文件是唯一变更入口。

## 2. 适用范围与总原则

- **数学范围**:单变量 `x`、整系数域(char 0)、次数 ≤ 8 的多项式;输出全部相异根
  及各自正重数。复系数、有限域、多变量一律拒绝(§11)。
- **重数只来自 SFF**:重数是分解层指标(§4.3),不是数值聚类结果——这是本契约与
  「浮点判重」路线的根本分界。
- **零存储原则**:C 侧错误码走返回值、输出缓冲由调用方提供,零 static 对象、零新视图,
  `.bss` 零增长(每个 static = TU 净 +32 B,ROADMAP.md:190;.bss 账本 == 级断言,
  ROADMAP.md:188)。复用 Pro union 的 poly/rat 槽(464 B,v2.3.0 起;ROADMAP.md:152
  「复用 poly 视图零增量」)。两侧全程显式循环:零递归、零 malloc
  (CONTRIBUTING.md:62(C)/ 83(JS);禁 malloc 由 Makefile --wrap 兜底,ROADMAP.md:191)。
- **从严拒绝**:文法与域之外一律拒绝,拒绝时给本契约 §7 的具体错误码,绝不硬解、
  绝不输出未验证的分解(apart 回乘验证同款纪律,ac_pro.h:395-398)。
- **确定性优先于观感**:渲染规则机械拼接、特例最少;凡规则与美观冲突,以规则为准。

## 3. 输入文法

### 3.1 字符集与长度

- 输入仅接受 ASCII:数字 `0-9`、`+ - * ^ x`、空格与水平制表符。其余任何字节
  (C 侧含全部 ≥0x80 的 UTF-8 字节;JS 侧含全部非 ASCII 码元,以及 U+0000)
  → `AC_PRO_SQF_EPARSE`。大小写从严:**只认小写 `x`**,`X` → `EPARSE`
  (与 ODE 的 y/x 同款:变量是固定语义角色,不接受换名)。
- 输入是 NUL 结尾的完整串(C 侧 `const char *`;JS 侧 `string`)。长度上限 **128 字节**
  (不含 NUL);空串或超长 → `EPARSE`。(最坏合法形态:9 项 × `-999*x^8` ≈ 80 B,
  128 留余量。)
- 空白 = 空格 + tab,允许出现在任意词法单元之间,**但数字串内部与 `^` 之后到次数
  首数字之间不允许空白**(`1 2x` 是系数 `1` 后紧跟非法数字 → `EPARSE`;
  `x^ 2` → `EPARSE`,同 ODE 撇号序列纪律,ode 契约 §3.1)。

### 3.2 词法单元

| 单元 | 形态 | 说明 |
|---|---|---|
| 系数 | `[0-9]+` | 十进制无符号整数,允许前导零(`03x` ≡ `3x`);解析期溢出 int64 早退 → `ECOEF` |
| 变量 | `x` | 任意项中出现,次数恒 ≥ 1 的载体 |
| 幂记号 | `x` 后紧连 `^` 再紧连 `[0-9]+` | 次数 n ∈ [1,8];n = 0 → `EPARSE`(常数项直接写整数);n ≥ 9 **当场** → `AC_PRO_SQF_EDEG`;允许前导零(`x^02` ≡ `x^2`) |
| 隐式乘号 | 无 | 系数与 `x` 直接相邻(`3x^2`);显式 `*` 亦合法(`3*x^2`),**每项至多一个**,且只能出现在系数与 `x` 之间 |
| 项分隔 | `+` 或 `-` | 项首可再带一个符号(`-x^2`、`+-3x` 合法,gb 先例:项首符号消费 ac_pro_groebner.c:134) |

### 3.3 文法(逐字)

```
input := 项 { 分隔 项 }
项    := [符号] [系数] [ "*" ] [ "x" [ "^" 次数 ] ]   ← 系数与 x 至少出现其一;
                                                         `*` 须夹在系数与 x 之间,
                                                         悬空(`3*`、`*x`)→ EPARSE
分隔  := '+' | '-'
符号  := '+' | '-'                                    ← 仅项首;项首与分隔连用时逐字符消费
次数  := [0-9]+                                       ← 值 1..8;0 与 ≥9 的裁决见 §3.2/§7
```

硬规则(每条独立可测,判定全序见 §7):

1. **系数与 `x` 至少出现其一**。裸符号(`+`、`-`)、裸 `*`、`3*`、`*x` → `EPARSE`。
2. **顺序固定**:系数在前、`x` 在后(`x*3`、`x3` → `EPARSE`);`x` 之后仅允许
   `^`(紧连次数)、空白、`+`/`-`/串尾,出现 `*`(`x*3`)或其他 → `EPARSE`。
3. **同次项禁止重复**(`x^2+3x^2`):第二处即 → `EPARSE`(ode 契约 §3.3-2 同款)。
   合并同类项是**调用方**的义务。
4. **`=` 一律非法**——本契约收多项式,不收方程:`x^2-1=0` → `EPARSE`
   (剥 `=` 是调用方义务;方程求解走既有 solve 管线)。
5. `/`、`.`、括号、`√` 等一切文法外字符 → `EPARSE`。**非整系数在文法层即拒**:
   `0.5*x^2`(`.`)、`1/2*x^2`(`/`)都进不了系数域(§8;系数域只有整数,
   ode 契约 §10 同款)。

### 3.4 解析产物 → 系数数组与域判定

设项的次数为 k、系数为 c(带符号),累加进 `a[k]`(k = 0..8,`a[k]` 初值 0)。

- n = 最高使 `a[n] ≠ 0` 的 k;高于 n 的零系数自然不进入多项式,中间零系数原样保留
  (`x^8-1` 的 `a = [-1, 0, 0, 0, 0, 0, 0, 0, 1]`)。
- 全部 `a[k] = 0`(输入 `0`)→ `AC_PRO_SQF_ECOEF`(零多项式,§4.4)。
- 任一 |a[k]| > 999 → `AC_PRO_SQF_ECOEF`。
- **n = 0(非零常数)不是错误**——良定输出为空列表(§4.4)。这是对 ODE 契约
  (无导数项 → ECOEF)的刻意偏离,理由见 §4.4,两契约各自自洽、不互改。
- **系数域 |c| ≤ 999,比 rat 的 9999 严**(AC_PRO_RAT_COEF_MAX,ac_pro_scratch.h:93)。
  理由:Cauchy 界 |r| < 1 + max|a_k|/|a_n| ≤ 1 + 999 = 1000(本原整数多项式
  |a_n| ≥ 1),使 §5.4 fmt 的 `x·1e12 < 2^53` 无损缩放论证与有理重建 q ≤ 1000 值域
  覆盖论证(|r| ≤ 1000 恰被 p ≤ 10⁶+1 全覆盖)**逐字继承** ode 契约 §5.1-2/4,
  不重开跨语言确定性分析。sqfree 是新的根渲染模块,与 ODE(999)同域而非与 rat 同域。

## 4. square-free 分解管线(整系数域,循环式)

### 4.1 预处理:本原化

容度 `cont = gcd(|a_0|..|a_n|)` 除净、首项系数化正(ac_pro_rat_gcd 的本原化先例,
ac_pro.h:385)。容度与整体符号**不产生根、不进输出**(2x²−2 与 x²−1 同输出,
§6.2)。本原化只缩小系数绝对值,不会重新越域。

### 4.2 循环递推(逐字)

```
f_1 ← 本原部分;i ← 1
while deg(f_i) ≥ 1:                        ← 迭代数 L ≤ deg f ≤ 8;显式循环,零递归
    g_i ← gcd(f_i, f_i')                   ← 整系数欧几里得 GCD,本原归一(ac_pro.h:385 同款)
    h_i ← f_i ÷ g_i                        ← 整系数精确除;余式非零 → EINTERNAL
    f_{i+1} ← g_i
    i ← i + 1
对 j = 1..L:q_j ← h_j ÷ h_{j+1}           ← h_{L+1} := f_{L+1};本原归一下恒为 1
                                              (Gauss:f_i 本原 ⇒ gcd(f_i,f_i') 本原)
                                              ;余式非零 → EINTERNAL
```

### 4.3 层因子与重数(重数的唯一来源)

设本原部分 `f = Π p_e^e`(p_e 互异首一不可约)。char 0 下 `p_e'` 与 `p_e` 互素,故
`gcd(f, f') = Π p_e^{e-1}`;归纳可得 **`h_j = Π_{e ≥ j} p_e`,从而
`q_j = h_j / h_{j+1} = 重数恰为 j 的不可约因子之积`**。诸 q_j 两两互素、各自无重。

- `deg(q_j) = 0` 的层(该重数无因子)跳过,不产生任何输出项。
- 账本断言:`Σ_j j·deg(q_j) = deg f`;不成立 → `EINTERNAL`
  (ode 契约 §4.3 自检恒等式同款)。
- **重数语义(本契约的根基)**:输出项 (r, m) 的 m 只能是 r 所属因子的层指标 j——
  由整系数 GCD 精确决定;浮点比较只用于 §5.2 的实/复判定与 §5.3 的排序,
  **永不用于重数合并**(ROADMAP.md:149)。「重根只出一次」由 q_j 无重 + 两两互素
  **结构性保证**,不靠数值聚类、不需容差判重。

### 4.4 f' = 0 与常数的边界(写死)

char 0 下 `f' = 0 ⟺ f 为常数`,两种终态:

- **f 全零**(输入 `0`)→ `AC_PRO_SQF_ECOEF`:每个复数都是根,重数无定义
  (gcd(0,0) 拒绝先例,ac_pro.h:387)。
- **f 非零常数**(deg 0,如 `7`)→ **成功,输出 `[]`**(0 个根)。SFF 循环
  `deg < 1` 不进体,无需任何特判;与 SymPy `roots(7, x) = ∅` 对齐。
  **刻意偏离 ODE 契约**(ode §3.4 无导数项 → ECOEF):ODE 的常数特征方程没有
  通解族,而常数的 (根,重数) 列表良定为空——两契约各自自洽,不互改。

## 5. 求根、标注与渲染

### 5.1 次数域与路径矩阵(e / d 标注,一次定死)

| 无重因子 q_j 的次数 | C 侧路径 | 标注 | JS 侧路径 |
|---|---|---|---|
| 1..4 | 上游精确根式管线(硬限 [1,4],C/128KB/src/ac_solvers.c:752) | `e` | 同级精确根式(solveQuadratic/Cubic/Quartic,ode 契约 §4.1 同款) |
| 5..8 | Durand-Kerner(ac_pro_solvers_ext.c:88/:119-137;max_iter 200、tol 1e-12、Aberth 初值) | `d` | **不存在**——JS 侧整题 ≥5 即拒绝 |

- **路由按因子次数,不按整题次数**:`(x-1)^4·(x^2+1)` 整题 6 次,但两因子均 ≤4,
  全部标 `e`(§6.2 实例);反之 `x^8-1` 整题 8 次、唯一因子即 8 次,整表标 `d`。
- **整题次数域**:C ≤ 8(AC_PRO_NUMROOT_MAX_DEG,ac_pro_scratch.h:72),≥9 →
  `EDEG`(**§3.2 词法层当场**);JS 侧**整题 ≥ 5 即 `EDEG`**(guardDegree 口径,
  ROADMAP.md:23/:150;JS 无 DK 对应物)。同码不同域,是本契约唯一的双侧行为分叉,
  §9/§10 的对拍分层随之;≥9 两侧一律拒绝。
- **DK 只吃无重因子**:q_j 无重 ⇒ DK 对重根的已知弱点(两点重合需扰动,
  ac_pro_solvers_ext.c:132-133)被 §4 的管线次序**结构性规避**——这是 SFF 先于
  求根的次序理由。
- **`d` 标注的确定性**:DK 收敛到 1e-15 量级(ac_pro_solvers_ext.c:120-121 实测)
  ≪ 1e-9 的 fmt 判定域 ⇒ `d` 根的串形态同样双侧确定(§5.4);`d` 标注的是
  **管线来源**,不是数值不可信(整数根过 DK 照样整判命中,§6.2 第 10 行)。
- 求根失败(DK 不收敛 g_solve_error=3、上游错误码非 0)→ `EINTERNAL`,
  **绝不硬凑渲染**(ode 契约 §4.3 同款)。

### 5.2 实/复判定与共轭完整性

- **实根**:`|im| < 1e-9` → 实根,项只带 re(CONTRIBUTING.md:96 跨语言容差;
  ode 契约 §4.3 同款阈值)。
- **复根**:实系数多项式的复根成共轭对,**两个成员各出一项**(与
  tests/polynomials.json 的根多重集合口径一致)。断言:非实根 u 必存在配对 v:
  `|re(u)−re(v)| < 1e-9` 且 `|im(u)+im(v)| < 1e-9` 且 im 一正一负;残缺 →
  `EINTERNAL`,绝不硬凑(ode 契约 §4.3 同款)。
- **跨因子近邻不合并**:两不同因子的根落入同一 1e-9 邻域时仍各出各项——重数合并
  只属 §4 的整系数层,浮点近邻绝不触发合并;输出序由 §5.3 的并列规则定序。

### 5.3 排序(渲染顺序的根源)

全部项(≤ 8)在输出前执行**稳定插入排序**:

- 主键 Re **降序**;Re 相等(`|Δre| < 1e-9`)时按 Im **降序**;Im 相等判定同容差。
- 排序后的项序就是 §6 的输出序,**与底层求根器的内部输出顺序无关**(两侧求根器
  输出顺序不同也不影响最终字符串——ode 契约 §4.2 同纪律:根序写进契约,
  不留给实现)。

### 5.4 fmt —— 根值到字符串(继承,不重定义)

与 ODE 契约 §5.1、apart(ac_pro.h:403-404)**同一三级 fmt**,双侧自实现,
**禁止**直接调用平台 `printf("%.12f")` / `snprintf` / `Number.prototype.toFixed`:

1. 整数判定 `|x − round(x)| < 1e-9` → 整串(含 `"0"`,不输出 `-0`);
2. 有理重建 q = 1..1000,容差 1e-9,平局取 q 小、再 |p| 小 → `p/q`;
3. 定点 12 位、半连舍(round-away)、去尾零再去点。

有效域 |r| < 1000(§3.4 Cauchy 界):`x·1e12 < 2^53`(JS 双精度缩放无损)与
有理重建值域覆盖两段论证逐字继承 ode 契约 §5.1-2/4。fmt 收到域外输入属实现缺陷
→ `EINTERNAL`。

## 6. 输出格式(逐字)

### 6.1 项语法

```
out  := "[" item { ", " item } "]"     ← 至少一项;f 为非零常数时恰为 "[]"(§4.4)
item := 根 "@" 标注 重数
标注 := "e" | "d"                      ← e = 精确根式管线,d = DK 数值管线(§5.1)
重数 := [1-9][0-9]*                    ← 十进制,1..8(§4.3 层指标)
根   := 实根 | 复根
实根 := fmt(re)
复根 := [fmt(re)] ("+" | "-") [fmt(|im|)] "i"
```

- **复根特例(仅二,写死)**:re 部件经整数判定为 0 → 整段省略;|im| 部件为 1 →
  只写 `i`。故 `i`、`-i`、`2i`、`1+2i`、`-1/2-1/2i` 均合法形态。im 的符号由
  `"+"`/`"-"` 承载,数值恒取 |im|(共轭对的正半侧,ode 契约 §4.3 β = +|im| 同款)。
- 根串不含 `,` `@` `[` `]` ⇒ item 与 out 的切分无歧义。
- 输出为单行,无尾随空白、无换行符;C 侧写入调用方缓冲(不含 NUL 的字节数
  ≤ out_len−1,追加 NUL)。**失败时 out 内容未定义,调用方不得使用**
  (integrate 先例,ac_pro.h:242)。
- **out_len 冻结 ≥ 512**:最坏形态静态估算 = 8 项 × 复根 38 B(双部件各 18 B
  〔4 位整数 + 12 位定点 + 符号〕+ 连接号与 `i`)+ `@d1` 3 B ≈ 41 B,加 7×2 分隔
  与 2 边界 ≈ 344 B,512 留 1.4× 余量;不足 → `AC_PRO_SQF_EOVER`,且不写部分内容。

### 6.2 全覆盖范例(期望串逐字)

| 输入 | SFF 层(§4) | 期望输出(逐字) |
|---|---|---|
| `x^2-5x+6` | q1 = 全式(全 1 重) | `[3@e1, 2@e1]` |
| `x^2-2x+1` | q2 = x-1;q1 = 1 跳过 | `[1@e2]` |
| `x^3+x^2-5x+3` | q1 = x+3,q2 = x-1 | `[1@e2, -3@e1]` |
| `x^2+1` | q1 = x^2+1 | `[i@e1, -i@e1]` |
| `2x^2-2` | 本原化 x^2-1(§4.1),q1 | `[1@e1, -1@e1]` |

| `x^6-4x^5+7x^4-8x^3+7x^2-4x+1` | q4 = x-1,q1 = x^2+1;整题 6 次但两因子 ≤4 | `[1@e4, i@e1, -i@e1]` |
| `x^8-8x^7+28x^6-56x^5+70x^4-56x^3+28x^2-8x+1` | q8 = x-1;整题 8 次、重数 8、因子 1 次 | `[1@e8]` |

## 7. 错误码表(双侧同值,判定全序)

错误码走返回值/返回字段,**零存储**(每个 static = +32 B `.bss`,ROADMAP.md:190)。
JS 侧 `code` 字段取**同一套数值**。

| 值 | C 宏名 | 语义(触发例) |
|---|---|---|
| 0 | `AC_PRO_SQF_OK` | 成功,out 已写入(含 `[]` 空列表) |
| −1 | `AC_PRO_SQF_EPARSE` | 词法/结构错误:空串、超长(>128 B)、非 ASCII/非小写 x、裸符号/裸 `*`、系数与 x 顺序错、`x*3`/`x3`、同次项重复、`=`、`/`、`.`、括号、`x^0`、`^` 后非数字或夹空白 |
| −2 | `AC_PRO_SQF_EDEG` | 次数域:`x^n` 的 n ≥ 9(**词法层当场**)、整题 > 8(两侧)、**整题 ≥ 5(JS 侧,guardDegree 口径)** |
| −3 | `AC_PRO_SQF_ECOEF` | 系数域:|a_k| > 999、解析期 int64 溢出、全零多项式(输入 `0`)、SFF 中间整数溢出(ac_safe 纪律:溢出即拒绝,绝不回绕) |
| −4 | `AC_PRO_SQF_EOVER` | C 侧输出缓冲不足(out_len−1 < 输出字节数)。JS 侧字符串无此失败,**不产生** |
| −5 | `AC_PRO_SQF_EINTERNAL` | 整除余式非零(§4.2)、求根失败(DK 不收敛/上游错误)、共轭残缺(§5.2)、账本断言不平(§4.3)、fmt 越域。出现即实现缺陷或数值病态,绝不硬凑渲染 |

**判定全序**(从左到右扫描,首个可判定错误即返回;`EDEG` 在词法层当场):

```
EPARSE(字符/长度/结构) → EDEG(词法层当场) → ECOEF(域判定) → [SFF 期] ECOEF(溢出)
→ [求根渲染期] EOVER / EINTERNAL
```

即:`0.5+x^9` 报 `EPARSE`(从左到右 `.` 先命中);`x^9+0.5` 报 `EDEG`
(`x^9` 当场,先于后面一切);`1000*x^2+1` 报 `ECOEF`;`0` 报 `ECOEF`;
`7` 报 OK `[]`;JS 侧 `x^5-1` 报 `EDEG` 而 C 侧同输入为合法 DK 输入(§5.1 成文例外)。

## 11. 明确不做(超范围,按 §7 如实拒绝)

- **因式分解文本**(`(x-1)^2*(x+3)` 形态):本契约只出 (根, 重数) 列表;因子形态
  属 rat/gcd 家族(ac_pro_rat_arith/gcd/cancel/apart,ac_pro.h:382-412)。
- **符号根式渲染**(`√(2)` 形态):一切根走 fmt 数值串,标注只区分管线来源——
  exact-forms 的五分量模型不覆盖三次/四次一般根,强行渲染必引入双侧漂移
  (ode 契约 §10 同一结论)。
- **有理式 `p/q` 输入、分数/小数系数、多变量、复系数、负次数**:§7 对应码,不硬解。
- **有限域 / 模 p 的 SFF**(p | 重数时 gcd(f,f') 失效的经典情形):本契约只做
  char 0 整系数域;模 p 分解不属本契约。
- **≥9 次(C)/ ≥5 次(JS)**:`EDEG`,不硬解、不降级为近似整题输出。
- **方程入口**(`x^2-1=0`):剥 `=` 是调用方义务;方程求解走既有 solve 管线。
