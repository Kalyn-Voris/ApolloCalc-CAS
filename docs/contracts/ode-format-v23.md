## 1. 动机与用途

v2.3.0 的常系数线性 ODE 齐次通解是双侧并行开发的功能(C 侧归 feat/c-symbolic,JS 侧归
feat/js-pack,见 ROADMAP.md:169-170),而通解是**字符串进、字符串出**的功能:没有共享数据
结构,只有共享文本。若输入文法、根序、渲染拼法、错误码任何一处两侧各自理解,后果不是
"结果略有差异",而是 `tests/ode-solutions.json` 对拍全面失配、且无法定位是谁错
(ROADMAP.md:178 明文:两侧格式不一致即视为实现 bug,不允许返工兜底)。

因此先于两侧任何代码,把以下边界一次定死:

1. **输入文法**——什么串合法、什么串以哪个错误码拒绝(含非齐次/变系数/次数 >4 三类拒绝);
2. **特征多项式**——字符串如何映射为系数,系数如何映射为特征方程;
3. **根的归类与渲染**——单根、共轭对、实重根、重根×共轭(ROADMAP.md:108 点名"重根×共轭的
   渲染边界要一次定死")四类模板的逐字符拼法、根序、任意常数下标分配;
4. **数值格式化**——根值如何变成十进制串,使 C 的 `double` 与 JS 的 `number` 在同一输入上
   得到同一字符串;
5. **错误码语义**——一套数值,两侧同值,可精确比较(CONTRIBUTING.md:96:错误码用精确比较)。

用途:两侧实现者按本文件写码与写测试;收尾组按本文件建 `tests/ode-solutions.json`;
后续版本扩 ODE 能力时,本文件是唯一变更入口。

## 2. 适用范围与总原则

- **数学范围**:常系数、线性、齐次的常微分方程,未知函数固定为 `y`、自变量固定为 `x`,
  阶数 n ∈ [1, 4]。通解含 n 个独立任意常数。
- **零存储原则**:C 侧错误码走返回值、渲染缓冲由调用方提供,零 static 对象、零新视图,
  `.bss` 零增长(先例与论证:ac_pro.h:292;integrate 错误码区 ac_pro.h:321-336)。
  两侧全程显式循环:零递归、零 malloc(禁递归是红线,CONTRIBUTING.md:62(C)/ 83(JS))。
- **从严拒绝**:文法之外一律拒绝,拒绝时给本契约 §6 的具体错误码,绝不硬解、绝不输出
  近似通解(ROADMAP.md:74:"其余诚实报错")。
- **确定性优先于观感**:渲染规则机械拼接、特例最少;凡规则与美观冲突,以规则为准。

## 3. 输入文法

### 3.1 字符集与长度

- 输入仅接受 ASCII:数字 `0-9`、`+ - * = ' y x`、空格与水平制表符。
  其余任何字节(C 侧含全部 ≥0x80 的 UTF-8 字节;JS 侧含全部非 ASCII 码元,以及 U+0000)
  → `AC_PRO_ODE_EPARSE`。大小写从严:**只认小写 `y`/`x`**,`Y`/`X` → `EPARSE`
  (与 gb 解析器接受大小写的先例不同:ODE 的 y/x 是固定语义角色,不接受换名)。
- 输入是 NUL 结尾的完整串(C 侧 `const char *`;JS 侧 `string`)。长度上限 **256 字节**
  (不含 NUL);空串或超长 → `EPARSE`。
- 空白 = 空格 + tab,允许出现在任意词法单元之间,**但导数撇号序列内部不允许空白**
  (`y ''` 是 `y` 后跟非法字符 `'`,→ `EPARSE`;见 3.2)。

### 3.2 词法单元

| 单元 | 形态 | 说明 |
|---|---|---|
| 系数 | `[0-9]+` | 十进制无符号整数,允许前导零(`03y` ≡ `3y`);解析期溢出 int64 早退 → `ECOEF` |
| 导数记号 | `y` 后紧连 k 个 `'`(k ≥ 0) | k = 0 即未知函数本身;k ∈ [1,4] 合法;k ≥ 5 **当场** → `AC_PRO_ODE_EDEG` |
| 隐式乘号 | 无 | 系数与导数记号直接相邻(`3y''`);显式 `*` 亦合法(`3*y''`),**每项至多一个** `*` |
| 项分隔 | `+` 或 `-` | 项首可再带一个符号(`-y''`、`+-3y'` 合法,与 gb 先例一致:项首符号消费 ac_pro_groebner.c:129,分隔符不前进 :208) |
| 自变量 `x` | 系数位置(导数记号之前)任意出现 | **不属于本文法**;出现即置变系数标志(§3.4、§6 判定全序);**导数记号之后尾随 `x`(`y''x=0`)→ `EPARSE`**(§3.3-1 项尾硬校验,v2.4.1 裁决)。系数位置的 `x` 幂(`x^2*y=0`)按多项式语义消费幂值、仅置标志不报结构错(§3.3-3,v2.4.1 裁决) |

### 3.3 文法(逐字)

```
input    := 项 { 分隔 项 } '=' 右端
项       := [符号] [系数] 导数记号          ← 系数可缺省为 1;导数记号必备(缺 y → EPARSE)
分隔     := '+' | '-'
符号     := '+' | '-'                        ← 仅项首;项首与分隔连用时逐字符消费
右端     := { 空白 } '0' { 空白 }            ← 去首尾空白后必须恰为单个 '0'
```

硬规则(每条独立可测,判定全序见 §6):

1. **每项必须含恰好一个导数记号**。缺 y 的项(`3`、`+2`)→ `EPARSE`;
   导数记号后只允许 空白/`+`/`-`/`=`/串尾,出现 `*`(`y''*3`)、尾随 `x`(`y''x=0`,v2.4.1 裁决:与 `y''*3` 同一条项尾硬校验——若放行尾随 `x`,`y''*3` 的既有裁决即失去一致性)或其他 → `EPARSE`。
2. **同阶项禁止重复**(`y''+y''`、`y'+3y'`):第二处即 → `EPARSE`(与 gb 解析器对同变量
   重复报 EARG 的先例一致,ac_pro_groebner.c:162)。合并同类项是**调用方**的义务。
3. `^` 在**导数记号**上一律非法(导数阶只用撇号表示):`y^2+y=0` → `EPARSE`;`^` 紧跟
   **系数位置的 `x`**(`x^2*y=0`)按**多项式语义**处理——消费幂值(可空,与 C 侧
   ac_pro_ode.c:270-273 逐字一致)、仅置变系数标志,不报结构错(v2.4.1 裁决,采纳 C 侧
   行为,消除与 §6 EVARCOEF 行示例的矛盾)。括号、除法、小数、分数、
   函数记号(sin/exp/…)→ `EPARSE`。
4. 右端非 `'0'`(`y''=1`、`y''=x`、`y''=y`、`y''=x*x`)→ **不自动移项**,一律
   `AC_PRO_ODE_ENONHOMO`(右端含 `x` 属自由项非零,不是变系数;变系数只看左端)。
   右端空、或含文法外字符(`y''=;`)→ `EPARSE`。
5. 无 `=` → `EPARSE`。`=` 多于一个 → `EPARSE`(第一个 `=` 之后出现第二个 `=`)。

### 3.4 解析产物 → 特征多项式

设项的导数阶为 k、系数为 c(带符号),累加进 `a[k]`(k = 0..4,`a[k]` 初值 0)。
左端出现 `x` 记号时置变系数标志(此时照常完成词法,标志在 §6 全序中裁决)。

**映射(特征多项式)**:方程 `Σ_k a_k · y^{(k)} = 0` 对应特征多项式
`P(λ) = Σ_k a_k · λ^k`,即 **k 阶导数的系数就是 λ^k 的系数**。

- n = 最高使 `a[n] ≠ 0` 的 k;高于 n 的零系数因此自然不进入多项式,而**中间的零系数原样
  保留**(`a[k]=0` 就是 λ^k 项系数为 0,无"剔除"操作):
  `y'''+0y''+y=0` → `a = [1, 0, 0, 1]`,n=3,P(λ) = λ³ + 0·λ² + 1。
- `a[n] ≠ 0` 恒成立;n = 0(输入无任何导数项,如 `y=0`、`3y=0`)→ `AC_PRO_ODE_ECOEF`
  (P 为常数,无通解族)。
- 全部 `a[k] = 0`(恒等式 `0y=0`)→ `AC_PRO_ODE_ECOEF`(无穷多解,非通解族,拒绝)。
- 任一 |a[k]| > 999 → `AC_PRO_ODE_ECOEF`(系数域见 §4.4 的确定性论证;999 使根的
  Cauchy 界 ≤ 1 + 999 = 1000 < 4096,保证 §5.1 的 fmt 有效域)。

例:`y''+3y'+2y=0` → `a = [2, 3, 1, 0, 0]`,P(λ) = λ² + 3λ + 2(n=2);
`2y'''-y=0` → `a = [-1, 0, 0, 2]`,P(λ) = 2λ³ − 1(n=3)。

## 4. 特征根:求解、排序、聚类

### 4.1 求根管线(复用,不新写求根器)

- **C 侧**:n=1 线性根 `λ = -a[0]/a[1]`;n=2..4 走上游 `ac_solvers` 1..4 次精确根式管线
  (上游硬限 max_degree ∈ [1,4] 已验证:C/128KB/src/ac_solvers.c:752)。
- **JS 侧**:n=1 同上;n=2..4 复用 `solveQuadratic` / `solveCubic` / `solveQuartic`
  (core_solvers.js:46 / 192 / 295)。**注意系数序:JS 的 `_coeffs` 是低位在前
  `[c, b, a]`(core_solvers.js:41),传入前必须按此序摆放,不得倒置。**
- 求根产物统一为复数根数组 `(re[i], im[i])`,i = 0..n-1。虚部阈值按现有管线惯例
  (|im| 极小的根按实根处理,见 4.3 的 1e-9 判定)。

### 4.2 排序与相等判定(渲染顺序的根源)

在聚类**之前**,对 n 个根执行**稳定排序**(显式插入排序,n ≤ 4):

- 主键 Re **降序**;Re 相等(判定:`|re[i] − re[j]| < 1e-9`,CONTRIBUTING.md:96 的跨语言
  容差)时按 Im **降序**;Im 相等判定同容差。
- 排序后的根序就是 §5.3 的渲染顺序,**与底层求根器的内部输出顺序无关**(两侧求根器
  输出顺序不同也不影响最终字符串——这是把根序写进契约、而不是留给实现的原因)。

### 4.3 聚类与重数(显式循环,禁止递归)

按排序后顺序线性扫描,聚类规则(全部用 1e-9 判定式写死):

- **实根**:`|im| < 1e-9` → 实根 λ = re。相邻实根 `|λ1 − λ2| < 1e-9` 合并为同一根,
  重数累加(判据链:`|im| < 1e-9` 先于一切配对)。
- **共轭对**:实根判据不中后,与后续最近的未配对根 v 配对,当且仅当
  `|re(u) − re(v)| < 1e-9` **且** `|im(u) + im(v)| < 1e-9` **且** im(u) 与 im(v) 一正一负。
  配对成功 → 组 (α, β),其中 **α = re(u),β = +|im(u)|(恒取正)**,组重数按 x 幂层累加
  (同 αβ 的下一对并入同组,重数 +1)。
- **配不上**(某根既非实根又无共轭对象,或共轭对残缺):**数值病态或实现缺陷**,
  → `AC_PRO_ODE_EINTERNAL`,**绝不硬凑渲染**("绝不返回错值"纪律,ac_pro.h:133 同款)。
- 自检恒等式:Σ(实根重数) + Σ_共轭组(2 × 层内重数) = n,故渲染出的任意常数总数 = n
  (实现可作断言,失败 → `EINTERNAL`)。

## 5. 通解渲染

### 5.1 数值格式化 fmt(x) —— 跨语言确定性

fmt 是唯一把 `double`/`number` 变成字符串的地方,规则写死,**双侧实现同一算法**,
**禁止**直接调用平台 `printf("%.12f")` / `snprintf` / `Number.prototype.toFixed`
(平台间舍入与最短表示行为不保证一致;两侧都按下面步骤自实现):

1. **整数判定**:`|x − round(x)| < 1e-9` → 输出 `round(x)` 的十进制整串(含 `"0"`、负号)。
   (此分支同时覆盖 |x| < 1e-9 → `"0"`,不会输出 `-0`。)
2. **有理重建**(吸收求根噪声,可证明的确定性):在 q = 1..1000 中取 p = round(x·q)
   (q ≥ 1,p 为 int64),既约化(gcd 归一,q 恒正),满足 `|x − p/q| ≤ 1e-9` 的候选中
   取 |x−p/q| 最小者;平局取 q 小者,再平取 |p| 小者。命中 → 输出:
   q=1 时整串 `p`;否则 `p/q`(负号在前,如 `-3/2`)。
   *确定性论证*:两个不同既约分数 p1/q1 ≠ p2/q2(q ≤ 1000)距离 ≥ 1/(q1·q2) ≥ 1e-6 ≫ 2e-9,
   故 1e-9 邻域互不相交——只要 C/JS 两侧的数值根落在同一真值的 1e-9 邻域内(容差纪律保证),
   重建结果**必然同串**。p = round(x·q) 的值域(≤ 10⁶+1)完全覆盖 §3.4 系数域产生的根域
   (|λ| ≤ 1000),q ≤ 1000 的枚举不会漏配。
3. **定点 12 位**(非有理根,数值路径):s = round-away-from-zero-半连舍(x·1e12)
   (平局取远离零一侧,即 C `llround` 语义,JS 侧按同语义自实现);整数部分 = |s| / 1e12
   向零截断,小数部分 = |s| % 1e12 左补零至 12 位,**去尾零,再去小数点**;负号在最前。
   例:fmt(√2) = `"1.414213562373"`,fmt(-0.5) = `"-1/2"`(有理重建分支,输出 p/q
   形态),fmt(1/3) = `"1/3"`(重建分支),fmt(-1/3) = `"-1/3"`。
   (**收尾组修订注记,2026-10-31**:本例原写作 fmt(-0.5) = `"-0.5"`,与 §5.1-2
   规则「否则输出 p/q」及 §5.4 第 11 行冻结期望串 `-1/2` 自相矛盾;两侧实现
   (ac_pro_ode.c / core_ode.js)与两侧测试套件均已按 p/q 形态交付并通过,故将
   本示例改正为 `-1/2`,仅为文档内部自洽化,无行为变更。)
4. **有效域**:经 §3.4 系数域保证 |x| < 4096,故 x·1e12 < 2^53(JS 双精度缩放无损)且
   < 2^63−1(int64 无溢出)。fmt 收到域外输入属实现缺陷 → `AC_PRO_ODE_EINTERNAL`。

### 5.2 项模板与省略规则

通解 = `"y = "` 前缀 + 项列表,项间**一律** `" + "` 连接(任意常数的符号恒正,负号只出现在
λ/α/β 的数值内部,如 `exp(-2*x)`)。

每项由四段机械拼接(全部用显式 `*`,与 integrate 输出家族一致,test_pro_integrate.c:63-100):

```
项 := C_i [ *x^j ] [ *exp( E ) ] [ *cos( fmt(β)*x ) | *sin( fmt(β)*x ) ]
      常数   x 幂因子      e 指数因子        三角因子(仅共轭对)
```

省略与拼写规则(唯二特例加两条拼写细则,再无其他):

1. **x 幂因子**:j = 0 → 整段省略;j = 1 → `*x`;j ≥ 2 → `*x^j`。
2. **e 指数因子**:E = `fmt(α或λ) + "*x"`(α/λ = 0 时 E = `"0*x"`);
   **当 α(或 λ)经整数判定为 0 时,整个 exp 因子省略**——这是全文唯二特例之一
   (纯虚根/零根是教科书最常见形态,`exp(0*x)` 视为渲染缺陷)。
3. **三角因子**:仅共轭对有;β 恒正(§4.3),参数恒为 `fmt(β)*x`,**不做任何特例**
   (β=1 时写 `cos(1*x)`,不简写)。
4. **任意常数**:`C₁ C₂ C₃ C₄`(U+2081..U+2084,UTF-8 三字节;UTF-8 是本仓库既有输出
   风格,exact-forms.json 的 `√(2)` 同款)。**按下标连续递增分配,起点 1,渲染顺序即
   分配顺序,总数 = n**。
5. 输出为单行,无尾随空白、无换行符;C 侧写入调用方缓冲(不含 NUL 的字节数 ≤ out_len−1,
   追加 NUL)。**失败时 out 内容未定义,调用方不得使用**(integrate 先例,ac_pro.h:231)。

### 5.3 根类 → 项的展开(四类模板,一次定死)

设当前根簇下一段常数下标从 c 起(渲染顺序 = §4.2 排序序;实根按重数逐层,共轭对先 cos
后 sin、再进下一层):

| 根类 | 展开(j = 0..重数−1) |
|---|---|
| 单实根 λ(重数 1) | `C_c*exp(fmt(λ)*x)`;λ=0 → `C_c` |
| 实重根 λ(重数 k≥2) | 对 j=0..k−1:`C_{c+j}*x^j*exp(fmt(λ)*x)`(x 因子按 §5.2-1 拼写);λ=0 → 省 exp 因子 |
| 共轭对 α±βi(重数 1) | `C_c*exp(fmt(α)*x)*cos(fmt(β)*x) + C_{c+1}*exp(fmt(α)*x)*sin(fmt(β)*x)`;α=0 → 两组各省 exp 因子 |
| 共轭对 α±βi(重数 k≥2) | 对 j=0..k−1:各生成一对(先 cos 后 sin):`C*[*x^j]*exp(fmt(α)*x)*cos(...)` 与 `C*[*x^j]*exp(fmt(α)*x)*sin(...)`,常数下标连续递增;α=0 → 每项省 exp 因子 |

**重根×共轭的 x 幂拼写**:`x^j` 因子紧跟常数之后(cos 与 sin 项各自携带),j=1 写 `*x`,
j≥2 写 `*x^j`,与实重根拼写规则完全一致。

### 5.4 全覆盖范例(期望串逐字,含全部四类)

| 输入 | 特征根(按 §4.2 排序) | 期望输出(逐字) |
|---|---|---|
| `y''+3y'+2y=0` | −1, −2 | `y = C₁*exp(-1*x) + C₂*exp(-2*x)` |
| `y''-3y'+2y=0` | 2, 1 | `y = C₁*exp(2*x) + C₂*exp(1*x)` |
| `y''+2y'+5y=0` | −1±2i | `y = C₁*exp(-1*x)*cos(2*x) + C₂*exp(-1*x)*sin(2*x)` |
| `y''+4y=0` | ±2i | `y = C₁*cos(2*x) + C₂*sin(2*x)` |
| `y''-4y'=0` | 4, 0 | `y = C₁*exp(4*x) + C₂` |
| `y''-2y'+y=0` | 1(实重 2) | `y = C₁*exp(1*x) + C₂*x*exp(1*x)` |
| `y'''-y'=0` | 1, 0, −1 | `y = C₁*exp(1*x) + C₂ + C₃*exp(-1*x)` |
| `y''''-y=0` | 1, ±i, −1 | `y = C₁*exp(1*x) + C₂*cos(1*x) + C₃*sin(1*x) + C₄*exp(-1*x)` |
| `y''''+2y''+y=0` | ±i 各 2 重 | `y = C₁*cos(1*x) + C₂*sin(1*x) + C₃*x*cos(1*x) + C₄*x*sin(1*x)` |
| `y'=0` | 0 | `y = C₁` |
| `2y''+2y'+y=0` | −1/2±(1/2)i | `y = C₁*exp(-1/2*x)*cos(1/2*x) + C₂*exp(-1/2*x)*sin(1/2*x)` |

(逐行核对 §4.2:Re 降序,故 `y''+3y'+2y=0` 的 −1 先于 −2、`y''''-y=0` 的次序是
1 → 共轭对 ±i → −1。第 5 行 λ=0 走 exp 省略特例;第 9 行纯虚二重走共轭对模板 + x 层;
第 11 行有理重建给出 `-1/2`/`1/2`——两侧无论求根浮点差多少,1e-9 邻域必命中同一
分数,§5.1-2。)

## 6. 错误码表(双侧同值,判定全序)

错误码走返回值/返回字段,**零存储**(论证:ac_pro.h:292——任何 static 都让 C 侧 TU
净增 32 B `.bss`,直接威胁 42608/42640 门禁)。JS 侧 `code` 字段取**同一套数值**。

| 值 | C 宏名 | 语义(触发例) |
|---|---|---|
| 0 | `AC_PRO_ODE_OK` | 成功,out 已写入 |
| −1 | `AC_PRO_ODE_EPARSE` | 词法/结构错误:空串、超长(>256 B)、非 ASCII/非小写、缺 y、缺 `=`、同阶项重复、`^`/括号/函数记号、`*` 位置非法、撇号间空白、右端空或含文法外字符 |
| −2 | `AC_PRO_ODE_EDEG` | 导数阶 ≥ 5(撇号计数到 5 **当场**返回) |
| −3 | `AC_PRO_ODE_EVARCOEF` | 变系数:左端出现 `x` 记号(`x*y''+y=0`、`x^2*y=0`) |
| −4 | `AC_PRO_ODE_ENONHOMO` | 非齐次:右端去空白后非单个 `'0'`(`y''=1`、`y''=y`、`y''=x`) |
| −5 | `AC_PRO_ODE_ECOEF` | 系数域:|a[k]|>999、全部为零(恒等式)、最高非零阶为 0(无导数项) |
| −6 | `AC_PRO_ODE_EOVER` | C 侧输出缓冲不足(out_len−1 < 输出字节数)。JS 侧字符串无此失败,**不产生** |
| −7 | `AC_PRO_ODE_EINTERNAL` | 求根结果无法按 §4.3 归类(聚类失败/共轭残缺)、fmt 收到有效域外输入。出现即实现缺陷或数值病态,绝不硬凑渲染 |

**判定全序**(从左到右扫描,首个可判定错误即返回;延迟标志最后裁决):

```
EPARSE(字符/长度/结构)  →  EDEG(词法层当场)  →  EVARCOEF(x 标志,仅当全串无 1/2 类错误
且右端合法时升级)  →  ENONHOMO  →  ECOEF  →  [求根渲染期] EOVER / EINTERNAL
```

即:`x*y''=1` 报 `EVARCOEF`(变系数先于非齐次);`x$+y''=0` 报 `EPARSE`(结构错优先于
x 标志);`y'''''+x=0` 报 `EDEG`(词法当场,先于一切标志)。

**v2.4.1 裁决(消除 §3.2/§3.3 与本表的两处文本矛盾)**:`x^2*y=0` → `EVARCOEF`
(多项式语义:系数是 `x` 的多项式即变系数,采纳 C 侧行为,JS 侧已对齐);`y''x=0` →
`EPARSE`(§3.3-1 项尾硬校验,C 侧行为,JS 侧已对齐)。两条已从 knownDeviations 移入
正式用例并双侧实跑冻结。

## 10. 明确不做(超范围,按 §6 如实拒绝)

- 非齐次(任何右端)、变系数(`x` 出现在左端)、阶 ≥5:§6 对应码,不硬解。
- Euler 方程(`x²y''+xy'+y=0` → −3,变系数)、解析/分数/小数系数(`1/2y''`、`0.5y'` → −1,
  系数域只有整数)。
- 多未知函数(`z''+y=0` → −1)、`^` 记号导数、括号、隐式方程、初值问题(无初值概念,
  只出通解)。
- 根式精确渲染(`√2` 形态):无理根一律走 fmt 12 位数值路径(§5.1-3),不做符号根式
  ——exact-forms.json 的五分量模型不覆盖三次/四次一般根,强行渲染必引入双侧漂移。
