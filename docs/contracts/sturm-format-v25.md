## 1. 动机与用途

F3 = benchmark-giac.md:128-129 成文对标缺口(Giac sturm/sturmab)的关闭:
单变量整系数多项式 → 本原化+首项化正 → square-free 预归一 → Sturm 链
p₀ = p, p₁ = p′, p_{k+1} = −rem(p_{k−1}, p_k)(**精确有理余**,规避伪余 prem 的
符号因子陷阱)→ V(a)−V(b) 计数(±∞ 端点首项符号+次数奇偶,零求值成本)→
显式栈二分隔离(禁递归)。DK 路径由此首次获得可验证的实根计数保证。

计数不是根式解,不触 guardDegree 的阿贝尔-鲁菲尼边界(features.md:168)。

## 2. 数学语义(一次定死)

### 2.1 Sturm 链构造

1. 解析 → 本原化(容度除净、首项化正;计数值对标量缩放不变)。
2. square-free 预归一:g = gcd(p, p′)(整系数,prem 逐步 content 约减;
   C 侧中间量溢出 → ECOEF);p_sf = p / g(精确整除,余式非零 → EINTERNAL)。
   **计数与隔离都作用于 p_sf 的相异根**(重根经 SFF 后只计一次;
   用例:(x−1)³(x+2)² → 2)。
3. 链:p₀ = p_sf;p₁ = p_sf′(不做符号修饰);p_{k+1} = **−rem(p_{k−1}, p_k)**,
   其中 rem 为 Q 上唯一带余除法的余式——实现为精确有理余后再整化:
   乘**正**最小公倍母线清分母 → 提正 content 约减 → **不做任何整体变号**
   (正数缩放不改变 V 计数;负号翻转变号,prem 符号陷阱在此被绕开)。
4. 链止于非零常数(gcd(p_sf, p_sf′)=1 保证); deg(p_sf)=0(常数)时链只有 p₀。
5. 存储:C 视图每系数上限 **8 limb(基数 1e9,72 位十进制 ≈ 239 bits)**;
   超限 → `ECOEF`(C 侧「系数膨胀离群」语义)。JS 链构造每步中间量
   (含 num/den 对与清母线)|v| > 2^53−1 → `ECOEF`(JS 侧审计语义)。

### 2.2 V(t) 符号变差计数

V(t) = 链各成员在 t 处符号序列(跳过精确 0)的变差数。
±∞ 端点:sign = sign(lc)·(±1)^deg(零求值成本)。

### 2.3 计数约定(冻结;PARI 旧版 ]a,b] 语义 + 端点闭修)

    count(a, b) = V(a) − V(b) + [p₀(a) = 0]     (有限 a ≤ b,闭区间 [a,b])

- 跳零变差下 V(a)−V(b) 计 (a, b];补项 [p₀(a)=0] 把左端点根计入,
  右端点根由 (a,b] 的闭端自然计入 → 闭区间 [a,b] 端点为根时计入。
- a = −∞ 或 b = +∞ 合法(混合亦可);a > b → `EPARAM`;a = b 合法
  (退化为 [p₀(a)=0])。
- p₀(a)=0 的判定是**精确**判定(端点是整数/有理数,C 用 ac_bigint 精确
  Horner;JS 用精确整数 Horner)。

### 2.4 隔离(显式栈二分,禁递归)

1. Cauchy 界 B = 1 + max|cᵢ|/|cₙ|(i < n),上取整到 2 的幂 → 初始区间
   [−B, B](端点为整数,精确)。
2. 单元格语义 = **半开 (lo, hi]**(cellcount = V(lo) − V(hi)),整棵二分树
   合并 [−B, B] 闭区间计数;若 p₀(−B) = 0(精确判定)则前置退化区间
   [−B, −B]。二分中点 = (lo+hi)/2,同一 2^dep 网格上精确。
3. cellcount = 0 → 丢弃;= 1 → 输出 [lo, hi];≥ 2 且深度 ≥ **48 层** →
   输出**未解析**区间(如实标注,绝不出假区间;两侧统一 48 层,不成为
   隐蔽分叉)。
4. 输出按 lo 升序;端点渲染为**既约分数**(母线 = 2^e,约去公因子 2):
   母线 1 写整数,否则写 `num/den`;负值带 `-`。未解析区间在串尾加 `!`。
   列表 = `[[a1, b1], [a2, b2], ...]`;无实根 = `[]`。
5. 深度上限 48 与 JS 精确域的相互作用(§5.2 R10 的落地):dualCases
   全部为浅隔离(实测域内相异实根间隔 ≥ ~1e-3,深度 ≤ ~12),
   深隔离用例归 cOnly-OVF(§7)。

## 3. 输入文法(计数与隔离共用)

- **词法 = sqfree 契约 §3 同域**:小写 `x`、整系数 |c| ≤ 999、次数 ≤ 8、
  ASCII、长度 ≤ 128 B、空白任意、隐式系数 1/次数 1、`*` 可选、同次项重复
  → EPARSE、`=`/`/`/`.`/括号/非 ASCII → EPARSE、次数 ≥ 9 当场 EDEG、
  全零多项式 → ECOEF、非零常数 → 成功(计数 0 / 隔离 `[]`)。
- 计数端点 a、b:`inf`/`-inf`(逐字,大小写敏感)或十进制整数
  |n| ≤ 999999(可带 `-`);其余(空串、小数、分数、其它记号)→ `EPARAM`。
- 隔离无端点参数。

## 4. API(C / JS)

- C(错误码走返回值,计数为非负成功值):
  `int ac_pro_sturm_count(const char *src, const char *a, const char *b);`
  → ≥ 0 计数,< 0 为 §7 错误码。
  `int ac_pro_sturm_isolate(const char *src, char *out, int out_len);`
  → 0 成功 / 负错误码;契约冻结 out_len ≥ 512,不足 → `EOVER` 不写部分内容。
- JS(ApolloSqfree 扩段,加载期一次分配槽复用):
  `sturmCount(src, a, b)` → 同 C 语义;`sturmIsolate(src)` → 错误码,
  `getSturmString()` 取输出串。

## 5. C/JS 分叉面(全部成文,不称对等)

### 5.1 次数分叉(cOnly-DEG 层)

- JS:deg ≥ 5 → `EDEG`(guardDegree 口径,与 sqfree §5.1 同机制);
  C:deg 5..8 全功能(DK 交叉校验的可选联动不阻塞验收)。

### 5.2 精确域分叉(cOnly-OVF 层;ECOEF 双语义冻结)

- **ECOEF 双语义**:C = 链系数超 8 limb(≥ ~2^239,域内 60K 样本实测峰值
  144 bits,防御码)或解析期 |c| > 999 / 全零;**JS = 链构造中间量或精确
  整数求值中间量超 2^53−1**(每步审计,绝不输出失真值)。
- JS 符号判定双轨(冻结):计数端点(整数)走**精确整数 Horner**(每步
  |v| > 2^53−1 → ECOEF——大端点用例由此触发 cOnly-OVF,如 deg 4 多项式在
  端点 10⁶ 处 Horner 中间量 ~10²⁴);隔离二分点走**浮点 Horner + 前向误差界**
  (界 = 2·γ·Σ|cᵢ||t|ⁱ,γ ≈ deg·2⁻⁵²,外加端点非精确表示修正),|v| > 界才
  定号,否则 ECOEF——该轨道对 dualCases 全程可判定(域内实根间隔 ≫ 机器
  精度),与 C 精确判定同结果,是 dual 零分叉的先决条件。
- **「刚好拒绝」钉死**:deg 4、|c| ≤ 999 的链构造中间量实测(40 万样本,
  BigInt 精确)峰值 47 bits < 2^53,判别式界给出的最小相异根间隔 ≥ ~1e-9·尺度
  ⟹ **域内链构造不可破 2^53、隔离深度不可达 42+(numerator ≤ 2^11·2^42 <
  2^53)**;cOnly-OVF 的可达触发面 = 大整数端点的精确 Horner(§2.4/§5.2)与
  理论离群(防御)。JS 侧「每步 |v|>2^53−1 即 ECOEF」为硬语义,判据以
  中间量精确整数值是否 ≤ 2^53−1 为准,与浮点可判定性无关。

### 5.3 数值域

- C 系数中间量 int64(SFF/链 content 约减期)溢出 → ECOEF;
  链存储 ac_bigint/8 limb。JS 全程 Float64 安全整数 + 2^53 审计。
- 端点整数域 |n| ≤ 999999:两侧同域;C 端点 Horner 由 ac_bigint 精确承载,
  JS 由 2^53 审计闸门拒绝(§5.2)。

## 6. 错误码全序(冻结;负值即失败)

| 码 | 名 | 语义 |
|---|---|---|
| ≥ 0 | (计数值) | count 成功,值为闭区间 [a,b] 内 p_sf 相异实根数 |
| 0 | OK(isolate) | 成功,out 已写入(含 `[]`) |
| −1 | EPARSE | 词法/结构错误(§3;含大写 X、`=`、非 ASCII、同次重复、悬空符号) |
| −2 | EDEG | 次数 ≥ 9(两侧)/ **JS:次数 ≥ 5(cOnly-DEG 成文分叉)** |
| −3 | ECOEF | C:|c|>999、全零、链系数超 8 limb;JS:链构造或精确求值中间量 > 2^53−1(双语义成文) |
| −4 | EPARAM | 端点不合法(格式/越域 \|n\|>999999)或 a > b |
| −5 | EOVER | C 输出缓冲不足(仅 C;JS 不产生) |
| −6 | EINTERNAL | SFF 除法余式非零 / 链构造账本不平 / 渲染越域(绝不硬凑) |

## 7. 契约用例与差分

- `tests/sturm.json` 三层:
  **dualCases**(deg ≤ 4 且 JS 精确域全程成立):计数精确整数、隔离区间端点
  既约分数精确、错误码精确——双侧零分叉;
  **cOnlyDEG**(deg 5..8):C 断言计数/隔离期望,JS 断言 EDEG;
  **cOnlyOVF**:C 断言真实计数/隔离,JS 断言 ECOEF(大端点 Horner 触发,
  含「刚好通过/刚好拒绝」端点边界对)。
- 差分驱动 `tests/bench/diff-sturm.js`:机制同 diff-smoke128.js,既有 50 例
  管线一行不动,exit 0 为验收线。
- 关键用例:全 5 实根(x⁵−5x³+4x)、零实根(x⁸+1、x²+1)、重根经 SFF 计数
  ((x−1)³(x+2)² → 2)、端点恰为根的开闭语义([−2,3] vs [−3,2] vs [−2,2])、
  ±∞ 与混合端点、a=b、负首项、非常数内容(6x²−6)、近根正常隔离(999x²−2)、
  cOnly 5..8 次、cOnly-OVF 大端点对、负向(>8 次 EDEG、JS ≥5 EDEG、非整系数、
  端点超域、a>b、零多项式、大写 X、「刚好拒绝」边界对)。
