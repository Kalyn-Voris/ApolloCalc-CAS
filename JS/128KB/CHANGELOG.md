# JS/128KB · 组件变更记录

本文件从**组件视角**记录 JS/128KB 的版本递进，格式遵循
[Keep a Changelog](https://keepachangelog.com/)。与根
[CHANGELOG.md](../../CHANGELOG.md) 的口径区分：根记录**全局版本节点**（仓库级 Tag，
一次发布可只覆盖部分组件），本文件记录**组件版本**（见本目录 [VERSION](VERSION)）。

## v2.4.3 (2026-11-03) · 对应全局 v2.4.3

  注释被 minify 管线剥离，压缩内核逐字节不变（103599 B）。无功能性变更。

## v2.4.1 (2026-11-01) · 对应全局 v2.4.1

- **修复 ODE 渲染缺陷**（core_ode.js）：`_isZeroInt` 三条退出路径混返 boolean/数字，
  实根渲染门 `=== 0` 严格比较失配，0<|λ|<0.5 且 llround(λ)=0 的小正有理根
  （1/3、1/999 等）exp 因子被误省略；统一恒返 0/1 数字后与 C 侧逐字一致。
- **解析器按多项式语义对齐 C 侧**：系数位置 `x^幂` 消费幂值仅置变系数标志（幂值可空，
  镜像 ac_pro_ode.c:270-273）；导数记号后尾随 `x` 改报 EPARSE（§3.3-1 项尾硬校验）。
- ODE 契约 v2.3 两处文本矛盾在 ode-format-v23.md 拍板；knownDeviations 清零，
  6 条用例双侧实跑冻结进 ode-solutions.json（70 → 76）。
- 压缩内核重建：103325 → 103575 B（预算 131072 B）。通过 1188 项测试。

## v2.4.0 (2026-10-31) · 对应全局 v2.4.0

- **符号微分**（新增 `core_symboltree.js`）：对表达式做解析式求导，覆盖四则、幂与 17 种
  常用函数；多项式可输出因式列表；支持隐函数求导 dy/dx。
- **符号积分**（新增 `core_integrate.js`）：128 项积分表与 C 侧逐项对齐，支持两层分部积分；
  错误码与 C 侧同值。
- **平方自由分解**（`core_ratroot.js` 扩展）：输出 (根, 重数) 列表，按
  [sqfree-format-v24](../../docs/contracts/sqfree-format-v24.md) 契约实现。与 C 侧的
  成文分叉：JS 侧只处理 4 次以内，≥ 5 次返回次数超限。
- **结式与 2 变量 Groebner 基**（新增 `core_groebner.js`）：输入总次数 ≤ 4。
  系数域为 Float64 安全整数，中间量绝对值超过 2^53−1 时返回溢出错误；C 侧用 int64，
  大幅值输入下两侧能力不对等。
- 压缩内核重建：`core_kernel.js` 49747 → 103325 B（预算 131072 B）。
- 通过 1183 项测试（20 个测试文件）。
- **待办**：全项目静态池升至 167908 B，已越过 98304 B 水位口径；现有水位检查只统计基础
  内核池、未计入模块池，故未拦截。**后续任何 JS 功能落位前应重估水位**。

## v2.3.0 (2026-10-31) · 对应全局 v2.3.0

- **数论模块**（新增 `core_numtheory.js`）：最大公因数 / 最小公倍数、素性判定、质因数分解、
  排列组合；安全整数域 ≤ 2^53−1，超限返回错误码。
- **矩阵升级到 12×12**（`core_matrix.js`）：行列式、逆、秩、LU 分解、QR 分解、实对称矩阵
  全部特征值与特征向量。原有 ≤3×3 闭式层行为保持不变。
- **常系数线性齐次微分方程通解**（新增 `core_ode.js`）：与 C 侧按同一契约实现，
  错误码同值。
- **多变量非线性守卫接入求解流程**：此前为死代码，现于多项式求解入口拒绝 2 变量及以上的
  非线性方程组。
- 压缩内核重建：`core_kernel.js` 34510 → 49747 B；静态池 22416 → 30112 B（水位门禁内）。
- 通过 862 项测试（16 个测试文件）。
- **已知缺陷**：微分方程存在 0 < |λ| < 0.5 且四舍五入为 0 的实特征根时（如 1/3、1/999），
  通解会漏掉对应指数项；C 侧同输入正确。负小根与共轭对分支不受影响。
  详见 [tests/ode-solutions.json](../../tests/ode-solutions.json) 的 `knownDeviations`。

## v2.2.0 (2026-10-27) · 对应全局 v2.2.0

组件版本轨道自本版建立，首个组件版本与全局版本同号；此后两轨各自独立递进，不必相等。
更早的沿革（v1.0.0 首版、v2.0.0 多变量与矩阵 / 特殊函数）见根 CHANGELOG。

- **内核压缩构建**：`node test/build-kernel.js --minify` 成为唯一重建入口，
  `core_kernel.js` 175142 → 57523 B（压缩率 67.2%）。
- **离线可复现**：压缩工具缺失或异常时自动回退到内置词法级剥离器，同入口、同全量校验，
  无网络环境用同一命令仍可构建（实测 175142 → 79435 B，压缩率 54.6%）。
- 通过 603 项测试（12 个测试文件）。
